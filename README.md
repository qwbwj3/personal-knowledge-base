# 个人知识库 · 1.2.0

面向 WorkBuddy 的本地个人知识库 Skill。Agent 负责阅读、分类、选材和回答；代码负责授权、来源修订、可恢复维护、索引与引用核验。

**本次为最终代码交付，用户的最终实机验收尚待执行。** 不把测试通过、安装成功或 OCR 高分当作全部资料正确、宿主已加载或问答已验收。

## 安装与使用

从发布者明确指定的 GitHub 仓库完整克隆，检出固定 40 位提交，再让 WorkBuddy 阅读 [安装流程](skills/personal-knowledge-base/references/installation-lifecycle.md) 和 [SKILL.md](skills/personal-knowledge-base/SKILL.md)。ZIP 仅供审阅和建立干净发布仓库，不是安装器的可信入口。最终验收步骤见 [FINAL-ACCEPTANCE.md](FINAL-ACCEPTANCE.md)。

首次告诉 Agent 资料目录、库名、保存位置和处理授权。已有资料增加时说“更新我的知识库”；目录用途可以持久保存，具体类别由 Agent 读正文判断，不靠文件名或首屏关键词决定。

可先处理可读取的内容；PDF 有未解决页时使用宿主视觉复核。缺少看图能力时告知用户并保留进度。普通文本分类不要求视觉模型。模型判断与本人确认分开保存。

## 发布内容

本树只保留运行代码、通用说明、依赖清单和有许可证的第三方组件。不含业务原件、提取结果、已建知识库、个人笔记、安装收据、模型、虚拟环境、实机日志、会话记录或凭据。通用空白模板不是用户的知识库。

核对文件集合：`python -B tools/verify_release.py`。文件清单只是完整性检查，发布提交/压缩包 SHA256 必须通过独立可信渠道核对。

**原私有开发仓库不能仅删除当前文件后直接改成公开。** 历史提交、旧分支、PR及Actions可能保留私有内容。干净发布树与原仓库可公开是不同结论，见 [PUBLICATION.md](PUBLICATION.md)。

## 范围与限制

支持格式与默认容量见 Skill 文档；复杂表格结构、真实大容量处理、独立备份恢复和目标宿主生命周期需要按实际环境验证。高置信 OCR 不保证字字正确，检索排名不是事实置信度。第三方组件许可见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。
